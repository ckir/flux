Performance & Benchmarks

Empirical evaluation comparing Flux against standard operating system transfer utilities.

Comparative Benchmark Chart

Measurement Methodology

Benchmarking file copiers reliably requires strict cache hygiene and steady-ratio calibration:

  • Cold vs. Warm Cache: Linux and macOS benchmarks run with an explicit cold cache to measure physical I/O throughput and scanning performance without OS page cache distortion. Windows benchmarks run with a warm cache to reflect standard workstation operating conditions.
  • Steady Calibration: A comparison pair appears on the published chart only after calibration runs demonstrate that variance across multiple executions has stabilized.
  • Identical Job Isolation: Every measurement runs in the exact same runner job, comparing Flux directly against the host platform's native tools (cp, rsync, and robocopy) under identical disk and CPU allocations.

Trend Tracking Over Time

Continuous integration captures benchmark histories across commits to guard against performance regressions. To explore historical data, inspect the automated CI benchmark output at bench/.
