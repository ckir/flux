About Flux

Reimagining filesystem replication with mathematical rigor and bounded resident memory.

Origins & Inspiration

Flux was created by Costas Kirgoussios to address a recurring failure point in systems administration: existing command-line copiers treat memory as an infinite resource and treat file verification as an afterthought.

While inspired by the speed and buffer management of FastCopy on Windows, Flux was built on an entirely new architecture written in Rust. Flux guarantees bounded resident memory regardless of dataset scale, enforces deterministic traversal ordering, protects destination directories with atomic locks, and cryptographically proves data integrity with BLAKE3 advisory checkpoints.

Core Engineering Tenets

  • Correctness Before Performance: High throughput is meaningless if bits are flipped, inodes are corrupted, or half-copied files masquerade as complete transfers.
  • Deterministic Traversal: Traversal order is strictly defined and repeatable, eliminating intermittent ordering bugs and ensuring identical results across runs.
  • Bounded Resource Footprint: Heap memory and open file descriptors are strictly bounded by design. Backpressure ensures discovery never outpaces consumer capacity.
