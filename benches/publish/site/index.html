Flux benchmarks

Each point is Flux's median time divided by a comparator's, both measured in the same GitHub Actions job. Below 1.0, Flux is faster. Six interleaved rounds per case; every copy is checked file by file (SHA-256). Linux and macOS drop the page cache before each copy; Windows cannot, and is measured warm, under its own heading. A pair is drawn only after a calibration (10 parallel runs) shows its ratio varies by at most 3%, and only on the runner image it was calibrated on. A new runner image breaks the line.

Cases: large, one 1 GiB file; small, 5,000 files of 4 KiB; mixed, 500 files totalling 512 MiB. Source: benches/publish/ in the repository.
