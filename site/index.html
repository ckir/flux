Extract and run

tar -xzf flux-x86_64-unknown-linux-gnu.tar.gz   # Linux and macOS: use the archive you downloaded
Expand-Archive flux-x86_64-pc-windows-msvc.zip . # Windows (PowerShell); or: unzip flux-x86_64-pc-windows-msvc.zip

The binaries are not code-signed, so macOS Gatekeeper or Windows SmartScreen may warn the first time you run one.

Quickstart

Run the extracted binary from its folder (or put it on your PATH).

Linux and macOS

./flux copy ./photos /mnt/backup

Interrupted? Run it again with --resume:

./flux copy --resume ./photos /mnt/backup

Windows

.\flux.exe copy .\photos D:\backup

Interrupted? Run it again with --resume:

.\flux.exe copy --resume .\photos D:\backup

Goals

  • High throughput, but correctness before performance
  • Bounded resident RAM regardless of tree size
  • Deterministic discovery and traversal ordering
  • Hardlink topology preservation, including exclusion-aware dependencies
  • Robust resume after interruption, with checkpoint validation
  • Source-mutation detection
  • Atomic publication where the filesystem allows it
  • Clear human and machine-readable (--json) reporting
  • Cross-platform behaviour on Linux, macOS and Windows with explicit capability detection

Pipeline

  1. Source
  2. Deterministic scanner
  3. Selection / filtering
  4. Bounded discovery stream
  5. Topology + planning state
  6. Bounded transfer queue
  7. Parallel workers
  8. Streaming hash / verification
  9. Commit / atomic rename
  10. Report

API docs

Rustdoc for each crate in the workspace. Private items are documented, so the audience is contributors.

  • flux-core — scanner, selection, identity, topology, planner, scheduler, workers, copy, verification, resume
  • flux-fs — portable filesystem abstractions
  • flux-platform — Linux, macOS and Windows implementations
  • flux-hash — streaming hashing (BLAKE3)
  • flux-ui — progress and terminal presentation
  • flux-cli — CLI parsing and dispatch; the flux binary

Status

Flux is in early implementation. flux copy, flux verify and flux cleanup work, with destination locking and resumable operations. flux benchmark does not exist yet.
