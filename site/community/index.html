Flux Community & Contributing

An open engineering culture prioritizing correctness, deterministic testing, and high-performance Rust.

Contributing to Flux

Flux welcomes contributions from systems engineers, performance enthusiasts, and filesystem specialists. All contributions must adhere to our core principle: correctness before performance.

  • Contributing Guide — Prerequisites, Justfile recipes, and testing conventions.
  • Code of Conduct — Community behavioral standards.
  • Security Policy — Responsible vulnerability disclosure protocol.

Developer Workflow & Testing

Flux uses just as a command runner for reproducible builds and automated quality gates:

  • just test # Run the entire workspace test suite
  • just check-all # Run linters, cargo deny, and doc checks
  • just pages-preview # Build docs and preview site locally

Discussions & Issue Tracking

To report defects, propose kernel fastpaths, or suggest platform optimizations, use our GitHub issue tracker:

  • GitHub Issues — Defect reports and reproducer datasets.
  • GitHub Repository — Source code and commit tree.
