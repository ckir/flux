Flux Workspace Crates

A clean, decoupled Rust architecture engineered for modularity, strict bounds, and zero unnecessary dependencies.

Architecture & Crate Boundaries

Flux is organized into six purpose-built crates. Every crate enforces strict separation of concerns, ensuring high testability and deterministic runtime behavior.

Engine Core

flux-core

The central orchestration engine. Implements the deterministic directory scanner, selection and exclusion filters, bounded discovery stream, topology planner, scheduler, transfer queue, parallel workers, and the advisory resume engine.

flux-core Rustdoc

Filesystem Layer

flux-fs

Portable filesystem abstractions. Provides destination directory locking, atomic file and directory replacement, capability detection (sparse files, extended attributes), and safe directory cleanup.

flux-fs Rustdoc

Platform Acceleration

flux-platform

OS-specific kernel syscall interfaces and zero-copy fastpaths. Implements copy_file_range and splice on Linux, clonefile and APFS extent cloning on macOS, and ReFS block cloning on Windows.

flux-platform Rustdoc

Cryptographic Hash

flux-hash

Streaming cryptographic integrity engine powered by BLAKE3. Manages chunk-level advisory checkpoint digests, incremental stream hashing, and verification audits.

flux-hash Rustdoc

User Interface

flux-ui

Interactive terminal progress and output formatting. Provides smooth, high-fps terminal progress bars, human-readable status summaries, and machine-readable structured NDJSON output streams.

flux-ui Rustdoc

CLI Dispatcher

flux-cli

Command-line driver and entrypoint. Parses user CLI flags, runs capability probes, dispatches flux copy, flux verify, and flux cleanup commands, and manages process exit codes.

flux-cli Rustdoc
