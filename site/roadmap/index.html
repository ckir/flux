Flux Development Roadmap

Structured multi-phase engineering plan delivering correctness-first file transfers.

Phase Progression

Phase 1 — Completed

Foundation & Scaffolding

Workspace architecture, 6 decoupled crates, GitHub Actions CI matrix on Linux, macOS, and Windows, cargo test harnesses, and automated release pipeline.

Phase 2 — Completed

Scanner & Bounded Discovery

Deterministic directory traversal, lexically ordered streams, bounded heap resident memory, and exclusion pattern matchers.

Phase 3 — Completed

Topology & Hardlink Planning

Inode graph discovery, hardlink clustering, cycle detection, exclusion-aware topology preservation, and symlink evaluation.

Phase 4 — Completed

Transfer Engine & Fastpaths

Multi-threaded worker pool, Linux copy_file_range, macOS clonefile, Windows ReFS block cloning, and atomic publication.

Phase 5 — Completed

Crash Resiliency & Resumability

Advisory checkpoint validation, BLAKE3 64 MiB chunk hashing, destination locking, partial file prefix re-validation, and safe cleanup.

Phase 6 — Active Development

Verification & Benchmarking

flux verify completed; remaining milestones include flux benchmark, multi-source verification, and expanded platform capability matrices.
