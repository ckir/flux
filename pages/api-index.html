Flux Workspace Documentation

A high-performance, safe, topology-aware filesystem transfer engine. Crate responsibilities follow §3 of the engineering specification.

  • flux-core — scanner, selection, identity, topology, planner, scheduler, workers, copy, verification, resume
  • flux-fs — portable filesystem abstractions
  • flux-platform — Linux, macOS and Windows implementations
  • flux-hash — streaming hashing (BLAKE3)
  • flux-ui — progress and terminal presentation
  • flux-cli — CLI parsing and dispatch; the flux binary

Private items are documented: every crate is publish = false, so the audience is contributors rather than downstream consumers.
