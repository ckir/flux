CLI Command Reference

Flux provides three primary operational commands:

flux copy

Transfers files and directories with destination locking, hardlink preservation, and atomic publication.

flux copy SOURCE DEST [--resume] [--restart] [--links=copy|skip] [--durability=normal|sync] [--json]

flux verify

Audits destination files against source trees using BLAKE3 streaming hashes without performing transfers.

flux verify SOURCE DEST [--links=copy|skip] [--cross-filesystems] [--hash=blake3] [--json] [--verbose]

flux cleanup

Safely cleans destination lock files and removes half-copied temporary artifacts left by interrupted processes.

flux cleanup DEST [--force] [--json]

Machine-Readable Output (--json)

All Flux commands accept --json, outputting structured NDJSON (Newline Delimited JSON) streams suitable for automation, monitoring, and GUI wrappers:

{"type":"progress","bytes_transferred":104857600,"files_transferred":1420,"current_file":"data/archive.tar"}
{"type":"checkpoint","file":"data/archive.tar","chunk":1,"digest":"f2d5a8..."}
{"type":"summary","status":"completed","duration_ms":4210,"total_bytes":2400000000,"errors":0}
