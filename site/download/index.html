Installation & Extraction

Linux & macOS

tar -xzf flux-x86_64-unknown-linux-gnu.tar.gz
chmod +x flux
./flux --version

Windows (PowerShell)

Expand-Archive flux-x86_64-pc-windows-msvc.zip .
.\flux.exe --version

The binaries are not code-signed, so macOS Gatekeeper or Windows SmartScreen may warn the first time you run one.
